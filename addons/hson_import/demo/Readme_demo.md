This level 1-1 (w6d01) layout from Sonic Frontiers using .hson files
generated by HedgeSet on .gedit file. HSON only includes level layout,
not models or collission - you need to include those separately.
You still need to manually set the starting position (PlayersManager),
fill in StageData and the next level in the GoalRing.

I've included the collission mesh as a reference.
